# CodeAlpha_FAQChatbot
CodeAlpha AI FAQ Chatbot is a project developed using Python that helps users get quick answers to frequently asked questions. It uses Natural Language Processing (NLP) to understand user questions and find the most relevant answers from a stored FAQ dataset.  The chatbot is built with Streamlit and uses NLTK and Scikit-learn to process questions and match them with available answers. It has a simple, modern interface where users can ask questions, choose suggested questions, and manage their conversations.  The chatbot covers topics such as Artificial Intelligence, Machine Learning, NLP, Python, and chatbots. The main goal of this project is to make finding answers easier and faster through an interactive chatbot.  **Technologies Used:** Python, Streamlit, NLTK, Scikit-learn, TF-IDF, and Cosine Similarity.
